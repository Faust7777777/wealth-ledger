# Claude 修正单：报价候选保持紧凑

日期：2026-07-28

基线：`origin/feat/pi-agent-frontend-followup @ 244fa18`。

## P0

当前 `_QuoteCandidates` 把所有 `suggested` 卡片放在聊天区 `Expanded` 外的普通 `Column` 中。候选较多时会挤掉聊天区，并可能在较矮窗口溢出，不符合“紧凑入口、不占满聊天区”。

修正要求：

1. 面板外层最多显示一条紧凑摘要或固定高度入口，例如“报价建议 10”；不要直接纵向展开全部候选。
2. 点击后进入有高度上限、可滚动的 sheet/dialog/子页，再展示候选卡片。
3. 补至少 10 条 `suggested` 候选在 360 与 1200 宽、较矮窗口下的回归；聊天消息区仍有可用高度且无 overflow。
4. 保留现有采用/忽略、409 重载、重复点击门控和来源复制行为。
