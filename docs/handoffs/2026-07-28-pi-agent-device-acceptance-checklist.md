## Windows

1. 启动并登录，确认右下角低强调 Agent 入口可见。
2. 打开 Agent 右栏，确认原导航栏的位置和宽度不变；关闭后主内容恢复完整宽度。
3. 新建一个会话、改名、切回主会话，再切回来；消息和所选模型应随会话切换。
4. 选择一张图片和一个 PDF/CSV，确认发送前显示缩略图或文件 chip，可单独移除。
5. 发送一个不涉及账务写入的短问题，确认流式正文不重复；切断网络再恢复后点“重连”，正文不应翻倍。
6. 打开报价建议入口；候选较多时应在可滚动 sheet 内显示，聊天区仍可见。
7. 打开自动任务设置和通知列表，确认入口、返回和 action 跳转正常。

## Android

1. 安装 APK、填写服务器地址并登录。
2. 打开 Agent 全屏页，唤起输入法；输入框应在键盘上方且消息列表仍可滚动。
3. Android 返回键应先关闭弹层或 Agent 页，不应直接退出 App。
4. 切换会话并查看历史图片、PDF/CSV chip；文件项不应出现图片解码空白框。
5. 执行一次断线重连，确认消息不重复；检查自动任务和通知页的返回行为。
